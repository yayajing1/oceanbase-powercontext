继续实现「混合检索」功能：

0. **先读 `qoder/docs/fts-facts.md`**：那是本机 seekdb 上**实测**出来的中文全文索引结论。
   关键事实（设计文档 2.3.2 节的假设有误，以实测为准）：
   - 默认解析器是 `space`，连续汉字会被当成一个超长 token 直接丢弃，**中文一条都命中不了**；
   - `ik` 是词级索引，且**服务端不切分查询串**，所以多字连续汉字（如 `对比学习`）查 0 条；
   - `ngram`（`ngram_token_size=2`）是滑动二元索引，索引里存在跨词边界的 `比学`、`索增`；
   - 因此**正确做法是：应用侧把连续汉字切成滑动二元串，用 `+` 连成 AND**，
     例如 `对比学习` → `+对比 +比学 +学习`，实测精确命中 p01；
     `检索增强` → `+检索 +索增 +增强`，实测精确命中 p04/p05。
   - `EXPLAIN` 确认走的是 `TEXT RETRIEVAL SCAN`，原生索引确实被使用。

0.1 **必须先修掉 `db.py` 的解析器顺序（上一轮遗留问题）**：

   - 重建后请实际执行一次 `init-db`，确认 `schema_meta.fulltext_parser` 变成 `ngram`。
