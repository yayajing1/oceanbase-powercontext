```text
继续实现「混合检索」功能：

1. 一次查询同时使用两类能力，并把结果合并：
   - **关键词全文检索**：在 seekdb 的原生全文索引上做 MATCH，中文必须能命中；
   - **结构化条件过滤**：年份区间、标签（多选 OR）、作者。
   两者必须在**同一条 SQL** 里同时生效（全文条件进 MATCH，结构化条件进 WHERE），
   不允许在应用层把全表拉出来自己算匹配。
2. 返回结果必须包含：片段正文、出处（来源文件 + 起止行号）、相关度分数，
   并标明该条是被全文命中还是被结构化条件命中。
3. 搜索词归一化：去掉标点、统一大小写、中英文之间补空格，让中文子串能正确命中全文索引。
   如果 MATCH 表达式对某些输入不合法，要有降级策略（例如逐词 OR，或退化为 LIKE 过滤），
   并且降级情况要在结果里如实标注，不能假装是全文命中。
4. 提供 `explain` 开关：打印实际执行的 SQL 与 `EXPLAIN` 结果，便于核对原生索引确实被使用。
5. 补测试：
   - 中文关键词命中用例（用样例笔记里的真实词，例如「对比学习」「检索增强」）；
   - 年份区间 + 标签 + 作者的结构化过滤用例；
   - 全文条件与结构化条件同时生效、互不干扰的用例。

不要改动导入与切块逻辑。

```
