# 阶段提示词：05-powercontext-memory.md

> 直接复制下面代码块的内容，粘贴给 Qoder（IDE / CLI 均可）。

```text
继续实现「记忆与跨会话复用」，这一轮接入 **PowerContext**：

1. 用 PowerContext（进程内 Core SDK：`powercontext.builtin.runtime.open_builtin_runtime`，
   文件后端，默认落在 `qoder/.state/powercontext.db`）保存三类记忆：
   - **用户画像**：研究方向、常用标签、当前在写的综述主题；
   - **复习记录**：每张卡片的评分历史、下次复习时间；
   - **薄弱点**：被评低分的卡片所对应的标签/主题。
2. 记忆必须**落盘**，进程重启后能读回（不能是内存里的临时变量）。
3. 读回的记忆必须**真的影响输出**，并在输出里**标明**哪些部分来自记忆：
   - 检索时用画像里的标签做加权/过滤提示；
   - 复习队列用复习记录直接给出待复习清单（而不是空队列）；
   - 薄弱点在队列/推荐里主动提示「这些主题你不熟」。
4. 提供 `memory show` 子命令把当前记忆原样打印出来，便于核对。
5. 补测试：写入记忆 → **换一个进程/新开 runtime 实例**读回 → 输出中可见其影响。

PowerContext 是赛题指定的必选技术，必须真实参与功能，不能只装组件测连接。
请在代码注释或 docstring 里写明：PowerContext 存的是「关于你的记忆」，
seekdb 存的是「资料」，两者分工清晰。

```
